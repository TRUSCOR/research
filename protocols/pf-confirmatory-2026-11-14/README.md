# PF confirmatory protocol (frozen 2026-11-14)

This folder fixes, before any of their attacked episodes were run, the rules of the studies
that extend the `.sova` paper: a verdict audit of AgentDojo results, a scoreboard of
current models, how often findings reproduce, a held-out test of comparability rules, and
upgrade checks. Read `PF-confirmatory-protocol-2026-11-14.md`.

`MANIFEST.sha256` lists the SHA-256 of every frozen file. Check it with:

```bash
sha256sum -c MANIFEST.sha256
```

The commit that added this folder, and the Software Heritage archive of this repository,
date the freeze. Custody is the author's own; no independent party holds these files.
Any later change is a deviation and is reported in the paper.
